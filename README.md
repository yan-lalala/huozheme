# 🌱 活着么 (Huozheme) - 每日手机解锁平安守护平台

> **“每日一次 · 解锁即安好”**  
> 专为独居青年、空巢老人、异地恋人打造的**无感平安守护系统**。手机每天只要第一次解锁屏幕，即可静默完成打卡报平安；圈子内亲友可实时查看健康状态，超时未解锁自动触发微信告警。

## ✨ 核心特性

1. **绝对静默，无需手动打开应用**：
   * 每天早晨正常关闹钟、扫脸或指纹解锁屏幕的瞬间，打卡已在后台 0.1 秒内完成。
   * 当天后续的所有屏幕解锁，本地和云端均自动防抖休眠，**零耗电、零网络开销**。
2. **手机重启依然自动生效**：
   * iOS 快捷指令属于操作系统级服务，永久常驻。
   * Android 内置 `RECEIVE_BOOT_COMPLETED` 开机广播监听，关机重启后系统自动拉起。
3. **圈层化共享与阶梯式安全告警**：
   * 支持创建家庭圈、密友圈、情侣圈，邀请码一键加入。
   * 成员状态直观展示：🟢 **已报平安** | 🟡 **等待中** | 🔴 **超时预警 (急需联系)**。
   * 可配置每人专属最晚预警时间（如 20:00、21:00），超时自动触发微信告警通知。

## 🚀 快速启动与本地体验

本项目开箱即用，内置演示数据与手机端模拟器：

### 1. 启动后端与前端页面
```bash
# 启动服务 (默认端口 3000)
npm start
```
服务启动后，在浏览器访问：**`http://localhost:3000`** 即可打开微信小程序风格的手机端看板。

### 2. 页面核心功能操作：
* **右上角身份切换**：支持在「我 (守护者)」、「老妈」、「老爸」、「阿明」之间快速切换视角，体验不同身份看到的圈子状态。
* **模拟手机解锁**：点击卡片右上角 **「模拟解锁」**，立即模拟一次真实的屏幕解锁打卡，观察页面从“等待打卡”瞬间变为“已报平安”。
* **模拟夜间超时巡检**：点击 **「巡检夜间超时告警」**，系统自动扫描超时未解锁成员，模拟弹出微信模板消息警报。
* **无感打卡配置**：点击该按钮查看 iOS 快捷指令配置链接或获取安卓伴侣代码。

## 📱 双端无感打卡实现方案

### 方案 1：苹果 iPhone (iOS 快捷指令自动化，零 App 依赖)

iPhone 用户无需安装任何外部应用，利用苹果系统自带的「快捷指令」即可：

1. 打开 iPhone 自带的 **「快捷指令」** App，切换到中间的 **「自动化」** 标签。
2. 点击右上角 **「+」**，搜索并选择触发条件：**「当 iPhone 解锁时」**。
3. 设置为 **「立即运行」**，并关闭 **「运行时通知」**（保证完全静默）。
4. 操作添加：**「获取 URL 的内容」**。
5. URL 填入你的专属打卡地址：
   ```text
   http://你的服务器域名/api/v1/ping?token=YOUR_TOKEN
   ```
6. 点击完成即可。

---

### 方案 2：安卓手机 (Android 守护伴侣 APK)

安卓端源码位于 `android/` 目录，编译后体积仅约 1.5MB：

* **源码核心结构**：
  * `UnlockReceiver.kt`：监听系统 `Intent.ACTION_USER_PRESENT`（解锁广播），比对本地日期后发送轻量请求，完成后当天休眠。
  * `BootReceiver.kt`：监听 `Intent.ACTION_BOOT_COMPLETED`，手机重启后自动激活。
  * `MainActivity.kt`：首次输入/扫描 Token，并一键申请系统电池白名单（防杀）。
* **用户设置只需 1 步**：在手机“应用设置”中开启 **“允许自启动”** 和 **“无限制电池优化”** 即可长期免维护。

## 🔌 API 核心接口说明

| 方法 | 路径 | 描述 |
| :--- | :--- | :--- |
| `GET / POST` | `/api/v1/ping?token=xxx` | **核心打卡 Webhook**，手机解锁时静默调用，具备天然幂等性 |
| `GET` | `/api/user/me?token=xxx` | 获取当前用户信息、今天是否打卡、加入的圈子 |
| `GET` | `/api/circles/:id` | 获取圈子详情与全员今日实时状态 (alive / pending / timeout_alert) |
| `POST` | `/api/circles` | 创建新圈子 |
| `POST` | `/api/circles/join` | 凭 6 位邀请码加入圈子 |
| `POST` | `/api/alerts/check` | 触发巡检未打卡超时预警，生成微信告警信息 |
